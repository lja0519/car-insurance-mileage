# 자동차보험 마일리지 특약 할인율 비교

국내 자동차보험 9개사의 연간 주행거리별 마일리지 특약 할인율을 공식 자료에서 모아, 구간표 그대로 계단형 그래프·순위표·엑셀 계산기로 비교한다.

**웹에서 보기:** https://lja0519.github.io/car-insurance-mileage/

> 할인율은 2026-10-25~26 기준으로 각 보험사 다이렉트 공식 페이지에서 수집한 값이다. 보험사가 할인율을 자주 바꾸므로 가입 전 해당 보험사에서 꼭 다시 확인할 것. 이 자료는 참고용이며 보험 가입 권유가 아니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 정규화 로직 + 데이터 무결성 테스트
npm run build      # 타입 검사 + 정적 빌드 → dist/
npm run excel      # data/raw_discounts.json → 마일리지_할인_계산기.xlsx (python3 + openpyxl)
```

`dist/`는 정적 파일이라 아무 웹 서버에나 올리면 된다 (`npm run preview`로 확인).

## 구성

| 경로 | 내용 |
|---|---|
| `data/raw_discounts.json` | **원본 데이터**. 보험사별 공식 구간·할인율·경계 포함 규칙·할인 방식·사진 조건·기준일·출처(URL, 인용문, 확인일). 비교 기준 표(`primary`)와 별도 표(`others`: 전기차·연령·차급·채널·구표)를 분리 |
| `src/lib/normalize.ts` | **그래프용 데이터 생성**. Union KM 계산, 특정 km 할인율 조회(`rateAt`), 순위(`rankAt`), 최대 할인(`maxDiscount`), 계단형 점 생성(`buildSeries`), 할인 금액(`amountAt`, 엑셀과 같은 원 단위 반올림), 주행거리 지점별 표(`pointRows`) |
| `src/main.ts` | 화면: 계단형 그래프(Chart.js), 보험료·km 입력·슬라이더·필수 지점 버튼, 순위표(할인액·할인 후 금액 포함), 500km 간격 주행거리별 할인율 표(할인율/할인 후 금액 전환, 최대−최소 %p), 보험사별 최대 할인율·자료 상태, Union KM, 별도 표·출처 |
| `scripts/build_excel.py` | 엑셀 계산기 생성 |
| `마일리지_할인_계산기.xlsx` | 엑셀 계산기 |
| `tests/` | 로직 단위 테스트 24개 + 실데이터 검증 33개 |
| `.github/workflows/pages.yml` | main 에 push 하면 테스트 → 빌드 → GitHub Pages 배포 |

### 할인율 조회 규칙 (`rateAt`)
- 구간 안의 거리 → 해당 구간 할인율 (`구간 적용(계산)`)
- 경계값 그 자체 → 약관 표기(`이하`/`초과`)에 따른 구간 (`표 경계값(직접 기재)`)
- 경계 포함 여부가 데이터상 불명확하면 → 값을 고르지 않고 `경계 불명확` + 후보값 표시 (현재 데이터에는 해당 없음: 9개사 모두 "N km 이하" 표기)
- 최대 거리 초과 → `할인 없음`, 표 자체 미확보 → `미확인`. 둘 다 0%가 아니라 null이며 그래프에 선을 그리지 않음
- 구간 사이 선형 보간 없음. 그래프는 구간마다 수평선, 인접 구간은 수직 연결

## 엑셀 계산기 사용법

`계산기` 시트의 노란 칸 두 개에 **할인 전 보험료(원)**와 **연간 주행거리(km)**를 입력하면 보험사별로 다음이 자동 계산된다.
할인율 · 적용 구간 · 할인액(원 단위 반올림) · 할인 후 금액 · 순위(1위 행 초록색) · 최고 할인 보험사 · 최저 할인 후 금액

- `할인율표` 시트: 원본 구간표. 계산기는 이 시트를 참조하므로 값을 고치면 결과도 따라 바뀜
- `필수지점_비교` 시트: 1,000~15,000km 10개 지점 × 9개사 (A열 거리 변경 가능)
- `Union_KM` 시트: 전체 경계값별 9개사 할인율
- `출처` 시트: 출처 URL·인용문·확인일
- 할인 최대 거리 초과는 할인액 0원, AXA처럼 표가 없는 곳은 금액을 계산하지 않음

## 비교 기준

개인용 승용차(비전기차), 계기판 사진 등록 **후할인**, **다이렉트 채널**, 조사일(2026-10-25~26) 현재 유효한 표.
연령·차급별 표가 있는 보험사는 한화 40~59세, KB 65세 미만, DB 30세 이상·일반승용, 흥국 중형·대형·다인승 기준. 감축할인·커넥티드 방식 할인은 제외(별도 표에 수록).

## 추가 확인이 필요한 항목

1. **AXA손해보험**: 2026-10-25 보험시기부터 새 할인율(전기·수소·하이브리드 49.0~11.1%, 23,000km까지). 일반 차량 구간별 값은 axa.co.kr 견적 화면에서 직접 확인 필요.
2. **메리츠화재**: 예시표 값이 실제 견적 할인율과 같은지 확인 필요. 적용 시작일 미기재. 사진 등록 기한 문구가 '1개월 이내'와 '7일 이내'로 서로 다름.
3. **DB손해보험**: 새 표 시행일이 표 제목은 2026-11-01, 선택 버튼은 2026-11-06으로 페이지 안에서 다름. 11월 이후 보험 시작이면 새 표(별도 표 '30세 이상 일반승용')로 바꿔 비교해야 함.
4. **전 보험사**: 설계사(오프라인) 채널 할인율은 미확인(다이렉트 기준만 수록).
5. **할인 적용 대상 보험료**: 삼성·KB·DB·메리츠·흥국은 긴급출동(·특약) 보험료 제외로 명시, 현대는 '일부 특약 제외 전 담보', 한화·하나·AXA는 미명시. 같은 할인율이어도 실제 금액은 달라짐.
6. 한화 선할인 특약, KB·AXA 선할인 표는 미확인이라 비교에서 제외.
